## Compression Techniques

### 1. Lossless Compression

Lossless compression reduces the image file size without permanently removing image data. The original image information can be recovered after decompression.

**Example:** PNG

### 2. Lossy Compression

Lossy compression reduces the file size by permanently removing some image information. This can result in some loss of image quality.

**Example:** JPEG

### 3. Image Size Compression

In this task, different compression methods are applied to an image and the resulting file sizes are compared to understand how compression affects storage requirements.

## Conclusion
